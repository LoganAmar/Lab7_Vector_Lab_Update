# Lab7_Vector_Lab_Update

Commands:
-h                 Display this help message
quit               Exit the program
clear              Clear all stored vectors
list               Display all stored vectors

Vector Operations:
a = 1 2 3          Create or update a vector
a = 1, 2, 3        Create vector using commas
a                  Display vector a
a + b              Add two vectors
a - b              Subtract two vectors
a * 2              Multiply vector by scalar
2 * a              Multiply scalar by vector
a x b              Cross product of two vectors
a . b              Dot product of two vectors
c = a + b          Store result in vector c

Notes:
- All vectors contain 3 components (x, y, z)
- Spaces are required around operators
